# Project: jillmetcalfe.github.io

## About the user
- Jill is not a coder — always explain terminal commands, git operations, and technical concepts in plain language
- Don't assume familiarity with programming jargon
- When suggesting commands, explain what each part does

## Project details
- Jekyll site using the al-folio theme style
- Hosted on GitHub Pages at jillmetcalfe.github.io
- Git remote: https://github.com/jillmetcalfe/jillmetcalfe.github.io.git
- Build: GitHub Pages builds automatically when changes are pushed to the `main` branch

## Key files
- `_config.yml` — site-wide settings (title, description, etc.)
- `_layouts/` — page templates
- `_includes/` — reusable HTML snippets (header, footer, head)
- `_sass/` — styling (variables, themes, base styles)
- `assets/css/main.scss` — main stylesheet entry point
- `_posts/` — blog posts
- `_pages/` — standalone pages (about, etc.)
